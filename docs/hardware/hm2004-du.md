# H3C HM2004-DU board reference

## Identified platform

The supplied device-tree source identifies the board as **H3C HM2004-DU** and
uses the Airoha AN7581 / EN7581 platform family. It describes, among other
things, SPI-NAND/UBI storage, Ethernet and switch ports, PON, USB, PCIe Wi-Fi,
LEDs, and a disabled `h3c,fmcs` node.

The DTS is a reference artifact, not a validated upstream device-tree
definition. Comments in the file explicitly mark some GPIO assignments and
board behavior as unverified. Confirm those details against the actual board
and a recoverable stock firmware before relying on them.
